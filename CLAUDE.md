# Shared coding agent instructions

Read AGENTS.md for project-specific authority, existing lane boundaries, and
review/release controls. Also apply the Karpathy-inspired principles available
in .agents/skills/karpathy-guidelines/SKILL.md:

- Surface assumptions and real uncertainty before coding.
- Implement the simplest adequate solution.
- Limit changes to the assigned task and clean only orphans created by your changes.
- Define verifiable acceptance criteria and report actual test evidence.

Project-specific instructions and owner-approved governance take precedence.
